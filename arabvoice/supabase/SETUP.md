# ArabVoice — إعداد قاعدة البيانات

هذه الملفات هي بداية تقنية للمشروع، وليست موقعاً مكتملاً بعد.

## ما الذي يفعله مخطط قاعدة البيانات؟
- ينشئ حسابات المستخدمين وملفاتهم الأساسية ومحفظة فارغة تلقائياً بعد التسجيل.
- يجهز جداول الغرف، والعضوية، والرسائل النصية، والهدايا، والعملات، والاشتراكات وطلبات السحب.
- يفعّل سياسات أمان أساسية (RLS)، ويمنع المستخدم من تعديل رصيده المالي مباشرة من المتصفح.

## الخطوة المطلوبة منك
1. افتح لوحة Supabase وأنشئ مشروعاً باسم **ArabVoice**.
2. افتح **SQL Editor** ثم **New query**.
3. افتح ملف `schema.sql` في هذا المجلد وانسخ محتواه كاملاً إلى الاستعلام.
4. لا تضغط Run قبل التأكد أن المشروع جديد وفارغ، لأن هذا الملف ينشئ أنواعاً وجداول جديدة.
5. نفّذ الاستعلام، ثم أرسل لي فقط: **تم تنفيذ schema.sql**. لا ترسل كلمات مرور أو مفاتيح سرية.

## ملاحظات مهمة
- هذا المخطط لا يشغّل الصوت الحي ولا المدفوعات ولا السحب الفعلي.
- لا نضع مفاتيح سرية في ملفات الواجهة أو GitHub.
- قبل فتح التسجيل العام أو التعامل بأموال حقيقية، يجب إكمال اختبارات الأمان، وتحديد صلاحيات المالك من جهة الخادم، وربط مزوّد دفع مناسب والالتزام بمتطلباته القانونية.
